## 十、总结：所有介词的统一规律

| 介词类型 | 中文落点 |
|----------|----------|
| 时间（at/on/in/during/after/before…） | 动词前 / 句首 |
| 地点（in/on/at/to/from/under…） | 动词前 |
| 范围（in/on/about/regarding…） | 动词前 |
| 方式（by/with/in/through/via…） | 动词前 |
| 目的（for/to…） | 动词前 |
| 原因（because of/due to/owing to…） | 句首 / 动词前 |
| 条件（without/under/despite/in spite of…） | 句首 / 动词前 |
| 关于（about/on/regarding…） | 动词前 |
| 伴随（with/without/for/to…） | 动词前 |
| 数量（about/over/under/above…） | 动词前 |

## 一句话总规律

> **几乎所有介词短语作状语 → 中文放动词前。**
> **只有原因、条件、让步类 → 常放句首。**
