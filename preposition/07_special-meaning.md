# 英文介词的特殊含义：最全总结

---

## 一、为什么介词有“特殊含义”？

介词的基本义是**空间/时间关系**（in=在里面，on=在上面…）。

但英语介词**引申义极多**，可以表示：
- 状态
- 方式
- 穿着
- 情绪
- 身份
- 原因
- 程度

**中文往往没有对应介词，翻译时要换成动词/形容词。**

## 十四、总规律：介词的特殊含义分类

| 类型 | 常见介词 | 中文对应 |
|------|----------|----------|
| 穿着 | in | 穿/戴 |
| 状态 | in/on/at/under | 处于……中 |
| 情绪 | in/with | ……地 |
| 特征 | with | 留/戴/带 |
| 方式 | in/by/with/on | 用/坐/通过 |
| 关于 | on/about | 关于 |
| 目的 | for/to | 为了 |
| 程度 | at/by/over/under | 以/超过/少于 |
| 身份 | of | 具有……的 |

## 十五、一句话总结

> **英文介词除了基本义（空间/时间），还有大量引申义：穿着、状态、情绪、特征、方式、关于、目的、程度、身份。**
> **中文往往没有对应介词，翻译时要换成动词/形容词/副词。**
> **这是英文用介词、中文用动词的典型差异。**
