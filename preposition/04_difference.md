下面把每个例句都拆成**按英文顺序直译（错误/别扭）** vs **正确翻译（插入顺序）**。

---

# 一、核心原理

```
英文顺序：主语 + 动词 + 方式 + 地点 + 时间
中文顺序：主语 + 时间 + 地点 + 方式 + 目的 + 动词
```

**翻译时的操作：**
1. 先找主干（主语 + 动词 + 宾语）
2. 把所有状语**提到动词前**
3. 多个状语按 **时间 → 地点 → 范围 → 方式 → 目的** 排列

---

# 二、逐句拆解

## 例句 1

**英文：** I met him in Tokyo yesterday.

**按顺序直译（错误）：**
> 我 遇见 他 在东京 昨天
> ❌ 我遇见他在东京昨天

**正确插入顺序：**

```
主语(我) + 时间(昨天) + 地点(在东京) + 动词(遇见) + 宾语(他)
```

> ✅ 我昨天在东京遇见他。

| 成分 | 英文 | 中文落点 |
|------|------|----------|
| 主语 | I | 我 |
| 动词 | met | 遇见 |
| 宾语 | him | 他 |
| 地点 | in Tokyo | 昨天**后**、遇见**前** |
| 时间 | yesterday | 主语**后**、地点**前** |

## 例句 8

**英文：** He quickly left.

**按顺序直译（错误）：**

**正确插入顺序：**

```
主语(他) + 方式(很快) + 动词(离开)
```

> ✅ 他很快离开了。

| 成分 | 英文 | 中文落点 |

## 例句 10

**英文：** I chatted with him in English in Tokyo yesterday.

| 成分 | 英文 | 中文落点 |

| 对象 | with him | 方式**后**、动词**前** |
| 方式 | in English | 地点**后**、对象**前** |
| 地点 | in Tokyo | 时间**后**、方式**前** |
| 时间 | yesterday | 主语**后**、地点**前** |

# 三、总规律：插入顺序口诀

```
英文：主语 + 动词 + 方式 + 地点 + 时间
       ↓ 翻译时全部提到动词前，重新排序 ↓
中文：主语 + 时间 + 地点 + 范围 + 方式 + 目的 + 动词 + 宾语
```

# 五、一句话总结

> **英文状语在动词后（方式→地点→时间），翻译时全部提到动词前，按“时间→地点→范围→方式→目的”重排。**
