# 定语和状语：从零开始

## 第一部分：定语

### 一、什么是定语？

**定语 = 修饰名词的词，回答“什么样的 / 哪一个”。**

看这两句：

| 句子 | 翻译 | 有没有定语 |
|------|------|-----------|
| I like code. | 我喜欢代码。 | 无 |
| I like **smart** code. | 我喜欢**聪明的**代码。 | 有：smart |

**“smart”就是定语，修饰“code”。**

> 定语回答：**什么样的？哪一个？**

### 二、定语修饰什么？

**定语只修饰名词（或代词）。**

| 英文 | 翻译 | 定语 | 修饰谁 |
|------|------|------|--------|
| **smart** code | **聪明的**代码 | smart | code |
| **red** apple | **红**苹果 | red | apple |
| **my** book | **我的**书 | my | book |
| a **tall** man | 一个**高**男人 | tall | man |

**规律：定语永远跟着名词走。**

### 三、什么词能做定语？

| 词性 | 例子 | 翻译 |
|------|------|------|
| 形容词 | **smart** code | **聪明的**代码 |
| 代词 | **my** book | **我的**书 |
| 名词 | **code** quality | **代码**质量 |
| 数词 | **three** books | **三**本书 |
| 介词短语 | a man **in black** | **穿黑衣服的**男人 |
| 从句 | the man **who came** | **来的那个**男人 |
| 非谓语 | **written** code | **写好的**代码 |

### 四、定语的位置：前置 vs 后置

**这是中英文最大的差异之一。**

#### 1. 前置定语（放名词前）

| 英文 | 翻译 |
|------|------|
| **smart** code | **聪明的**代码 |
| **my** book | **我的**书 |
| **three** books | **三**本书 |

**中文定语几乎都前置。**

#### 2. 后置定语（放名词后）

| 英文 | 翻译 | 说明 |
|------|------|------|
| a man **in black** | **穿黑衣服的**男人 | 介词短语后置 |
| the man **who came** | **来的那个**男人 | 从句后置 |
| code **written in Python** | **用 Python 写的**代码 | 分词后置 |

**英文的后置定语，翻成中文要前移。**

### 五、中英文定语位置对照

| 英文 | 直译（别扭） | 正确中文 |
|------|-------------|----------|
| a man **in black** | 一个男人**穿黑衣服的** | **穿黑衣服的**男人 |
| the man **who came** | 那个男人**来的** | **来的那个**男人 |
| code **written in Python** | 代码**用 Python 写的** | **用 Python 写的**代码 |

**规律：**
> 英文：短定语前置，长定语后置
> 中文：定语**几乎全部前置**

### 六、定语小结

| 项目 | 内容 |
|------|------|
| 作用 | 修饰名词 |
| 回答 | 什么样的/哪一个 |
| 位置（英文） | 短的在前，长的在后 |
| 位置（中文） | 几乎全在前 |
| 词性 | 形容词、代词、名词、数词、介词短语、从句、非谓语 |

## 第二部分：状语

### 一、什么是状语？

**状语 = 修饰动词/形容词/整句的词，回答“何时/何地/如何/为什么”。**

看这两句：

| 句子 | 翻译 | 有没有状语 |
|------|------|-----------|
| He works. | 他工作。 | 无 |
| He works **in Tokyo**. | 他**在东京**工作。 | 有：in Tokyo |

**“in Tokyo”就是状语，修饰“works”。**

> 状语回答：**何时？何地？如何？为什么？**

### 二、状语修饰什么？

**状语可以修饰动词、形容词、整句。**

| 修饰对象 | 例子 | 翻译 |
|----------|------|------|
| 动词 | He works **quickly**. | 他**很快地**工作。 |
| 形容词 | He is **very** smart. | 他**非常**聪明。 |
| 整句 | **Luckily**, he came. | **幸运的是**，他来了。 |

### 三、什么词能做状语？

| 词性 | 例子 | 翻译 |
|------|------|------|
| 副词 | He works **quickly**. | 他**很快地**工作。 |
| 介词短语 | He works **in Tokyo**. | 他**在东京**工作。 |
| 名词短语 | He left **yesterday**. | 他**昨天**离开了。 |
| 不定式 | He came **to help**. | 他**来帮忙**。 |
| 从句 | **When he came**, I left. | **当他来的时候**，我离开了。 |

### 四、状语分类

| 类型 | 回答 | 例子 | 翻译 |
|------|------|------|------|
| 时间 | 何时 | He left **yesterday**. | 他**昨天**离开了。 |
| 地点 | 何地 | He works **in Tokyo**. | 他**在东京**工作。 |
| 方式 | 如何 | He works **quickly**. | 他**很快地**工作。 |
| 原因 | 为什么 | He left **because of rain**. | 他**因为下雨**离开了。 |
| 目的 | 为了什么 | He came **to help**. | 他**来帮忙**。 |
| 条件 | 什么条件 | **If possible**, I'll go. | **如果可能**，我就去。 |
| 程度 | 到什么程度 | He is **very** smart. | 他**非常**聪明。 |
| 频度 | 多久一次 | He **always** wins. | 他**总是**赢。 |

### 五、状语的位置：中英文最大差异

#### 英文状语位置：灵活，爱放句末

| 位置 | 例子 | 翻译 |
|------|------|------|
| 句末（默认） | He works **in Tokyo**. | 他**在东京**工作。 |
| 句首（强调） | **In Tokyo** he works. | **在东京**他工作。 |
| 动词前 | He **quickly** works. | 他**很快地**工作。 |

#### 中文状语位置：几乎全在动词前

| 英文 | 直译（别扭） | 正确中文 |
|------|-------------|----------|
| He works **in Tokyo**. | 他工作**在东京** | 他**在东京**工作。 |
| He left **yesterday**. | 他离开**昨天** | 他**昨天**离开了。 |
| He works **quickly**. | 他工作**很快地** | 他**很快地**工作。 |

**规律：**
> 英文状语爱放句末（尾重原则）
> 中文状语几乎全放动词前

### 六、多个状语的顺序

| 语言 | 顺序 | 例子 |
|------|------|------|
| 英文 | 方式 → 地点 → 时间 | by bus to Tokyo yesterday |
| 中文 | 时间 → 地点 → 方式 | 昨天坐公交去东京 |

**对照：**

| 英文 | 中文 |
|------|------|
| I went **by bus** **to Tokyo** **yesterday**. | 我**昨天** **坐公交** **去东京**。 |
| She works **carefully** **at Google** **every day**. | 她**每天** **在谷歌** **仔细地**工作。 |

### 七、状语小结

| 项目 | 内容 |
|------|------|
| 作用 | 修饰动词/形容词/整句 |
| 回答 | 何时/何地/如何/为什么 |
| 位置（英文） | 句末为主，可句首/动词前 |
| 位置（中文） | 动词前为主 |
| 分类 | 时间、地点、方式、原因、目的、条件、程度、频度 |

## 第三部分：定语 vs 状语 总对比

| 项目 | 定语 | 状语 |
|------|------|------|
| 修饰谁 | 名词 | 动词/形容词/整句 |
| 回答 | 什么样的/哪一个 | 何时/何地/如何/为什么 |
| 位置（英文） | 短的在前，长的在后 | 句末为主 |
| 位置（中文） | 几乎全在前 | 动词前 |
| 例子 | **smart** code | works **in Tokyo** |
| 翻译 | 聪明的代码 | 在东京工作 |

## 第四部分：一句话总结

| 成分 | 一句话 |
|------|--------|
| 定语 | 修饰名词，回答“什么样的” |
| 状语 | 修饰动词/形容词/整句，回答“何时/何地/如何/为什么” |

**最大差异：**
> 英文定语可后置，中文定语几乎全前置。
> 英文状语爱放句末，中文状语几乎全放动词前。

## 第五部分：小练习

判断下划线部分是定语还是状语：

1. I like **smart** code.
2. He works **in Tokyo**.
3. The man **who came** is my friend.
4. He left **yesterday**.
5. **Red** apples are sweet.
6. He came **to help**.
我喜欢智能代码。
他在东京工作。
来的那个人是我的朋友。
他昨天离开了。
红苹果很甜。
他来帮忙了。

**答案：**

| 句子 | 成分 | 修饰谁 |
|------|------|--------|
| smart | 定语 | code |
| in Tokyo | 状语 | works |
| who came | 定语 | man |
| yesterday | 状语 | left |
| Red | 定语 | apples |
| to help | 状语 | came |
